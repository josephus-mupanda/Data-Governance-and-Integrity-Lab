# Data Governance and Integrity Lab

An AmaliTech lab on handling **customer data deletion requests across several jurisdictions**.

## Scenario

**ShopGhana** is a Ghana-based e-commerce company with customers worldwide. Three customers ask for their data to be deleted in the same week:

| Customer | Location | Regulation | Complication |
|---|---|---|---|
| Abena | Ghana | Data Protection Act, 2012 (Act 843) | Tax records must be kept |
| Lukas | Germany | GDPR | Strict one-month deadline; processors must be notified |
| Maria | California | CCPA/CPRA | Active return dispute; also opts out of the sale of her data |

## Deliverable

**[Multi-Jurisdiction Compliance Response Matrix](Multi-Jurisdiction%20Compliance%20Response%20Matrix.md)**, which contains:

- an executive summary of the outcome for each customer
- for each customer: legal rights analysis, exemptions, obligations, deadlines, penalties, action steps and a draft response
- a side-by-side comparison table of Act 843, GDPR and CCPA/CPRA
- a unified deletion workflow (Mermaid diagram) and an audit log template
- key insights and recommendations for ShopGhana

## Learning Objectives

- Compare how deletion rights, exemptions and deadlines differ between regimes
- Apply lawful retention exceptions without over-retaining data
- Write clear, compliant responses to data subjects
- Design one auditable process that meets the strictest rule that applies

> Academic exercise, not legal advice.
